## 📦 ÉTAPES INCLUSES DANS LE PROMPT

Le prompt couvre ces 8 étapes:

1️⃣  Modèles TypeScript
    → Toutes les interfaces nécessaires
    → Prêtes à copier-coller

2️⃣  Service Angular
    → AdminProductService
    → 2 méthodes GET (liste et détails)

3️⃣  Composant LISTE
    → Tableau Bootstrap complet
    → Pagination Bootstrap
    → Gestion page/size

4️⃣  Composant DÉTAILS  
    → Cards Bootstrap
    → Variantes détaillées
    → Images en grid

5️⃣  Interceptor HTTP
    → Authentification JWT
    → Ajoute le token automatiquement

6️⃣  Routing
    → Configurations routes
    → Guards (à implémenter)

7️⃣  Module Setup
    → Imports nécessaires
    → Configuration providers

8️⃣  Bootstrap Import
    → Styles CSS
    → Configuration angular.json

   - GET /api/admin/products/{id}

   - Obtenu via POST /api/auth/login
