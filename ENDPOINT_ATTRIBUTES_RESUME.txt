🚀 UTILISATION CÔTÉ ANGULAR

ÉTAPE 1 : Créer le service
  - Appeler GET /api/attributes/with-values
  - Stocker le résultat dans une variable

ÉTAPE 2 : Afficher les attributs dans le formulaire
  - Boucler sur chaque attribut
  - Afficher ses valeurs comme checkboxes/select

ÉTAPE 3 : Sélectionner les valeurs
  - Enregistrer les sélections de l'utilisateur
  - Créer des variantes avec les combinaisons

ÉTAPE 4 : Envoyer au backend
  - POST /api/products avec ProductCreateRequest
  - Inclure les variantes avec attributeValues
