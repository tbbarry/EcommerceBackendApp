📊 RÉSULTAT ATTENDU (STRUCTURE)

✓ Array de 3+ objets (selon vos données)
✓ Chaque objet a : id, name, values[], createdAt, updatedAt
✓ Chaque valeur a : id, value, createdAt, updatedAt
✓ Pas d'erreur 401 (authentification)
✓ Pas d'erreur 403 (autorisation)
✓ Pas d'erreur 500 (serveur)
✓ Statut HTTP 200 OK

════════════════════════════════════════════════════════════════════════════════════

🐛 TROUBLESHOOTING

ERREUR 404 Not Found
  → Vérifier que le serveur est démarré
  → Vérifier que l'URL est correcte
  → Vérifier que l'endpoint n'a pas de typo

ERREUR 401 Unauthorized
  → Cet endpoint ne devrait pas demander d'authentification
  → Vérifier la configuration @PreAuthorize du contrôleur

ERREUR 500 Internal Server Error
  → Regarder les logs du serveur
  → Vérifier qu'il n'y a pas d'exception dans AttributeServiceImpl

RÉSULTAT VIDE []
  → Vérifier qu'il y a des attributs dans la base de données
  → Créer des attributs + valeurs d'abord via les endpoints POST

➕ CRÉER UN ATTRIBUT + VALEURS (TEST)

# 1. Créer l'attribut
curl -X POST "http://localhost:8080/api/attributes" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d '{"name": "Taille"}'

# 2. Récupérer l'ID retourné (ex: 1)

# 3. Créer des valeurs pour cet attribut
curl -X POST "http://localhost:8080/api/attribute-values" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d '{"value": "S", "attributeId": 1}'

curl -X POST "http://localhost:8080/api/attribute-values" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d '{"value": "M", "attributeId": 1}'

curl -X POST "http://localhost:8080/api/attribute-values" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d '{"value": "L", "attributeId": 1}'

# 4. Tester l'endpoint /with-values
curl -X GET "http://localhost:8080/api/attributes/with-values"
