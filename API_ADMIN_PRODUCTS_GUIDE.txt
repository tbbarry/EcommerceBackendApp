📋 ENDPOINTS ADMIN POUR LA GESTION DES PRODUITS
===============================================

## 🎯 Objectif
Fournir deux endpoints REST protégés pour permettre aux admins de gérer les produits facilement côté front.

## 🔐 Sécurité
- Route : `/api/admin/products`
- Protection : `@PreAuthorize("hasRole('ADMIN')")`
- Tous les endpoints nécessitent une authentification avec le rôle ADMIN

---

## 📌 ENDPOINT 1 : Liste des produits (Global View)

**Endpoint :**
```
GET /api/admin/products?page=0&size=10
```

**Description :**
Retourne une liste paginée de tous les produits avec les informations essentielles pour un tableau de bord/grid.

**Paramètres Query :**
- `page` (optionnel, défaut: 0) - Numéro de page (0-indexed)

## 📊 Comparaison des deux endpoints

| Aspect | Liste (`GET /api/admin/products`) | Détails (`GET /api/admin/products/{id}`) |
|--------|-----------------------------------|-------------------------------------------|
| **Données** | Infos essentielles | Toutes les infos + variantes + images |
| **Cas d'usage** | Tableau de bord, grid produits | Édition/gestion détaillée |
| **Performance** | Rapide (moins de données) | Plus lent (données complètes) |
| **Pagination** | Oui | Non (un seul produit) |
| **Contient variantes** | Nombre seulement | Détails complets |
| **Contient stocks** | Total aggrégé | Détails par variante |

---

## 🏗️ Structure des données créées

### DTOs créés :

1. **ProductAdminListResponse** (Liste)
   - Pour l'affichage dans un tableau/grid
   - Infos générales du produit
   - Compteurs (variantes, stock)

2. **ProductAdminDetailResponse** (Détails)
   - Toutes les informations du produit
   - Liste complète des variantes avec stocks
   - Liste des images

3. **VariantAdminResponse** (Variante détaillée)
   - Infos de la variante
   - Stock associé
   - Attributs (taille, couleur, etc.)


## 🚀 Exemple d'utilisation côté frontend (Angular)

### Récupérer la liste des produits :
```typescript
// service: admin-product.service.ts
getProductsList(page: number = 0, size: number = 10): Observable<Page<ProductAdminListResponse>> {
  return this.http.get<Page<ProductAdminListResponse>>(`/api/admin/products`, {
    params: { page, size }
  });
}

// component
ngOnInit() {
  this.adminProductService.getProductsList().subscribe(response => {
    this.products = response.content;
    this.totalPages = response.totalPages;
  });
}
```

### Récupérer les détails d'un produit :
```typescript
// service
getProductDetail(id: number): Observable<ProductAdminDetailResponse> {
  return this.http.get<ProductAdminDetailResponse>(`/api/admin/products/${id}`);
}

// component (édition)
editProduct(id: number) {
  this.adminProductService.getProductDetail(id).subscribe(product => {
    this.form.patchValue({
      name: product.name,
      description: product.description,
      price: product.price,
      brand: product.brand,
      categoryId: product.categoryId
    });
    this.variants = product.variants;
    this.images = product.images;
  });
}
```
