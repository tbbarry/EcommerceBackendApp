📝 DTOs CRÉÉES (Dossier : src/main/java/com/backend/ecommerce/dto)

1. AttributeDto.java
   - DTO pour afficher un attribut avec ses valeurs
   - Contient : id, name, List<AttributeValueDto>, timestamps

2. AttributeValueDto.java
   - DTO pour afficher une valeur d'attribut
   - Contient : id, value, attributeId, timestamps

3. AttributeCreateRequest.java
   - DTO de requête pour créer un attribut
   - Contient : name (obligatoire)

4. AttributeValueCreateRequest.java
   - DTO de requête pour créer une valeur d'attribut
   - Contient : value, attributeId (obligatoires)

5. VariantFullRequest.java
   - DTO de requête pour créer une variante complète
   - Contient : sku, price, quantity, reservedQuantity, attributeValues

6. VariantAttributeValueRequest.java
   - DTO pour associer une valeur d'attribut à une variante
   - Contient : attributeValueId

7. VariantAttributeValueDto.java
   - DTO pour afficher les attributs d'une variante
   - Contient : id, attributeValueId, attributeName, etc.

8. ProductImageRequest.java
   - DTO de requête pour ajouter une image au produit
   - Contient : url, alt, isMain, displayOrder, visualAttributeValueId

9. ProductFullResponse.java
   - DTO de réponse complète pour un produit
   - Contient : infos produit + List<Variantes> + List<Images>

10. VariantFullResponse.java
    - DTO de réponse pour afficher une variante avec détails
    - Contient : sku, price, attributeValues, stock

11. VariantStockResponse.java
    - DTO de réponse pour afficher le stock d'une variante
    - Contient : quantity, reservedQuantity, availableQuantity

12. ProductImageDto.java
    - DTO de réponse pour afficher une image de produit
    - Contient : url, alt, isMain, order, visualAttributeValueId

🎮 CONTRÔLEURS CRÉÉS (Dossier : src/main/java/com/backend/ecommerce/controller)

1. AttributeController.java
   - GET /api/attributes - récupérer tous
   - GET /api/attributes/{id} - récupérer un
   - POST /api/attributes - créer (ADMIN)
   - PUT /api/attributes/{id} - modifier (ADMIN)
   - DELETE /api/attributes/{id} - supprimer (ADMIN)

2. AttributeValueController.java
   - GET /api/attribute-values - récupérer tous
   - GET /api/attribute-values/{id} - récupérer un
   - GET /api/attribute-values/by-attribute/{attributeId} - par attribut
   - POST /api/attribute-values - créer (ADMIN)
   - PUT /api/attribute-values/{id} - modifier (ADMIN)
   - DELETE /api/attribute-values/{id} - supprimer (ADMIN)

3. ProductController.java (ENRICHI)
   - GET /api/products/slug/{slug} - existant
   - POST /api/products - créer produit complet (ADMIN)
   - GET /api/products/{id}/full - récupérer produit complet
